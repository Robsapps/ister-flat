# Ister Tower A02 walkthrough

A walkable 3D model of a sample flat. It opens in any modern browser on a computer or a phone, with nothing to install.

**Open it here: https://robsapps.github.io/ister-flat/**

## How to move

- Computer: click the view, walk with W A S D or the arrow keys, drag to look around. R and F look up and down.
- Phone: left thumb walks, right thumb looks around.
- The room buttons and the small floor plan jump straight to a room.

## About the model

Built from the developer's floor plan. Door, window and furniture sizes are estimates.

Sofa, armchair, plants and vase come from the Khronos glTF Sample Assets, CC BY 4.0. The page uses three.js (MIT licence).

The whole page is the single file `index.html`. The 3D model is stored inside it, so there is nothing else to load.
